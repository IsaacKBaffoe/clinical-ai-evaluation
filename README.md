\# Clinical AI Evaluation



A small Python project for learning Git, GitHub,

machine learning project structure, and AI evaluation.



\## Purpose



This is a learning project and does not provide

real clinical predictions or medical advice.



\## Current Model



The project currently contains a simple

demonstration risk-classification function.
